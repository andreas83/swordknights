; The Tug of War
;
; The zone manifest for the duel: the zones of one strip, west to east, one file
; name per line. Read by scripts/duel/zones.gd.
;
; Comments start with ';', exactly as in a level file, and the first comment
; line is the strip's name. Paths are resolved against this file's own
; directory, so a strip can be moved without editing it.
;
; WHY A MANIFEST AND NOT A LONGER GRID
; A 200-column ASCII file is not reviewable: a diff of one shows a wall of
; unchanged stone around the three cells that moved, and nobody can tell which
; screen they are looking at. One file per zone keeps a change local to the
; screen it changes, lets a zone be reordered or replaced by editing one line
; here, and leaves scripts/world/ascii_level.gd exactly as it was -- the
; parser still parses one grid, and the sequencing lives with the mode that
; needs it.
;
; Three to five zones. Player one pushes west toward zone 1's gate, player two
; pushes east toward the last zone's gate, and the match starts in the middle.
;
; THE SHAPE OF THE STRIP
; Each zone is one screen with one set piece, and the stake rises toward each
; end, as it does across a Nidhogg level:
;
;   zone 3  the Mirror Court   the start; a raised tower, two ladders, no hazard
;   zone 2  the Cistern Court  spikes, with a stepping stone to cross on
;   zone 1  the West Gate      bare water one jump from the gate, at dusk
;
; and zones 4 and 5 are 2 and 1 reversed. About half of every zone's floor is
; open ground a respawn can use; tests/zone_strip_test.gd holds each zone to
; eight columns of it and the strip to more than half.

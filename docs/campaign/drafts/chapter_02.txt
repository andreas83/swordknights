;
; Chapter II of the Adventure. A DRAFT: docs/campaign.md is the design, this
; file is its level, 126 x 26. The golden hour -- the sun a hand above the
; roofs. The city is closing its gates, and the gates are counterweighted:
; weight is the chapter's verb.
;

; @channel 2 hold 4.0
; @channel 3 hold 2.2
; @channel 4 hold 1.2

; @channel 6 hold 1.6

; Legend, existing (scripts/world/tiles.gd):
;   #  solid        =  one-way platform    H  ladder       :  backdrop
;   ^  spikes       ~  water               @  spawn        *  relic
;   D  exit door    t  torch               p  sentinel
;   %  false wall   &  cracked wall/floor  L  inscription
;   A  arch   |  column   (architecture marks; the rest is dressed by rule)
; Legend, proposed (docs/campaign.md). None of these parse yet -- an unknown
; glyph reads as empty air, so play and prove the _static file instead:
;   o  pressure plate: a floor stone       !  portcullis, hung from a lintel
;   1-9  mason's mark: stone carved with a channel number. It wires the one
;        mechanism it touches. Same mark, same channel.
;   [ ]  a lift's platform at its home stop    '  the lift's travel
;   ,  crumbling stone     x  sun mirror (turned by the sword; starts facing up)
;   O  sun-seal door       Q  sun-sealed secret (a third seal)
;   z  scythe on a beat    i  spike slot on a beat
;   w  Bastion   j  Caracal   g  Glassbearer   Y  owl   E  the Eclipse
;
; Beat sheet, left to right (columns):
;   1. The road in (0-12). Spawn under the city wall's gateway. Plate 1 lies
;      across the road; its stone carries mark 1, and so does gate 1's
;      lintel. Step on it: the counterweight drops, the gate rises and
;      stays up.                             [counterweights: introduce]
;   2. The lift court (13-18). A ridden lift, five courses up to the
;      rampart. R1 on the stall; an expert hops the stall and grabs across
;      the shaft instead.                    [counterweights: develop]
;   3. The rampart (19-25). A sentinel walks it.
;   4. The courtyard (26-38). A Bastion is posted under the rampart's lip.
;      Jump off and plunge: his front is a wall, his helm is not. A shove
;      here only puts you against the rampart -- where secret B is.
;                                            [Bastion: introduce]
;   5. The race street (41-54). Plate 2 starts a four-second counterweight;
;      hop the stall at a run; gate 2 drops behind you. Secret A is the
;      cracked paving beside the stall.      [counterweights: develop]
;   6. Torch 1 (56).
;   7. The balcony (58-61). Optional: a grab, a sentinel on four tiles of
;      stone, R2.                            [the harder route]
;   8. The weighed gate (62-72). A Bastion stands on plate 3 and his weight
;      holds gate 3 open. Leap him and walk through -- or kill him and race
;      the 2.2-second fall from his plate.   [counterweights: twist]
;   9. The corridor (77-92). A Bastion posted in a corridor two tiles high:
;      no leap over him, no height to plunge from. Grab onto the roof, drop
;      through the hatch (down + JUMP), plunge.     [Bastion: twist]
;  10. Torch 2 (91), inside the corridor's far end.
;  11. The Long Arcade (93-119). Four plate-and-gate pairs, every hold set
;      to drop its gate about half a second behind a prince running flat
;      out: click, run, slam. A kerb in the first bay, a three-deep pit in
;      the third (its east wall is false: secret C), and a Bastion standing
;      on the last plate.        [counterweights + Bastion: master; SET PIECE]
;  12. The plaza (120-125). The door, in the gold, with the Mirror Tower
;      over the roofs.
;
; Secrets:
;   A. Race street, beside the stall: a cracked floor, two wide. Plunge it.
;      A cellar with a relic and SAME MARK / SAME GATE.
;   B. The rampart's face, where you land from the plunge: a false wall,
;      a relic.
;   C. The arcade's pit: its east wall is false. Losing that race pays.
;
; Relics: R1 (stall), R2 (balcony), and one in each secret: five.
; Par 1:45. Expert line, about 0:40: the stall and a grab instead of the
; lift; rebound double plunges; leap the weighed Bastion; never stand still
; at a gate.
;

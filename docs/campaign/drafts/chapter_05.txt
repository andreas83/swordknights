; The Sun Well
;
; Chapter V of the Adventure. A DRAFT: docs/campaign.md is the design, this
; file is its level, 115 x 64. Night. The last light the tower sent down is
; kept in the Well under the city, and the King has gone down after it.
; Underground the only light is fire -- and, at the very bottom, the kept
; sun. The Well's machinery keeps time: 72 beats a minute, which at 60 Hz is
; exactly 50 frames a beat.
;
; @time night
; @channel 4 beat 0
; @channel 5 beat 50
; (Directives are proposed; the foundation decides the final syntax.)
;
; Legend, existing (scripts/world/tiles.gd):
;   #  solid        =  one-way platform    H  ladder       :  backdrop
;   ^  spikes       ~  water               @  spawn        *  relic
;   D  exit door    t  torch               p  sentinel
;   %  false wall   &  cracked wall/floor  L  inscription
;   A  arch   |  column   (architecture marks; the rest is dressed by rule)
; Legend, proposed (docs/campaign.md). None of these parse yet -- an unknown
; glyph reads as empty air, so play and prove the _static file instead:
;   o  pressure plate: a floor stone       !  portcullis, hung from a lintel
;   1-9  mason's mark: stone carved with a channel number. It wires the one
;        mechanism it touches. Same mark, same channel.
;   [ ]  a lift's platform at its home stop    '  the lift's travel
;   ,  crumbling stone     x  sun mirror (turned by the sword; starts facing up)
;   O  sun-seal door       Q  sun-sealed secret (a third seal)
;   z  scythe on a beat    i  spike slot on a beat
;   w  Bastion   j  Caracal   g  Glassbearer   Y  owl   E  the Eclipse
;
; Beat sheet, from the top left down to the bottom right:
;   1. The night square (columns 0-23, rows 0-9). The Well's mouth stands
;      open, a glow far below. An owl on a cornice.
;   2. The mouth's ladder. On the rungs you are off the stone, and the owl
;      spreads its wings; you are down before it stoops, and it folds.
;                                            [owl: introduce]
;   3. The rim gallery (rows 10-12). Torch 1. The first scythe keeps time in
;      a doorway: watch it cut, go through in its rest. R1 past it. Secret A.
;                                            [blades: introduce]
;   4. Five tiles down, the spike corridor (rows 15-17): slots off the beat,
;      slots on it, a scythe off it. Run the rhythm.  [blades: develop]
;   5. The sump (columns 47-54). Five down; then a hop to the shelf and a
;      hang to the rim, under the second owl. Climb while it pulls up, or
;      jump and slash it. Secret B is in the sump's wall. Torch 2 on the
;      rim.                                  [owl: develop]
;   6. The throat (columns 63-64, rows 18-44). The lift down twenty-six
;      courses. A scythe every four, from alternate walls on alternate
;      beats: step across the platform.      [blades: twist; SET PIECE]
;   7. Torch 3, at its foot.
;   8. The antechamber (columns 65-85, rows 36-43). A sentinel. An owl over
;      the scythe's door: draw its stoop through the cut on the beat. Spike
;      slots under a second owl that takes anything that jumps: run them on
;      the beat instead of hopping them. Secret C. Torch 4 at the Vault's
;      door.               [owl: twist and master; blades: master]
;   9. The Vault (columns 86-111, rows 41-52). The Eclipse: docs/campaign.md,
;      "The Eclipse". A heart on each gallery.
;  10. Dawn. The kept sun rises up the Well; dawn's door fills with it and
;      opens.
;
; Secrets:
;   A. The rim gallery's floor by the ladder: cracked, two wide. A relic and
;      THE SUN / REMEMBERS.
;   B. The sump's west wall: false. A relic.
;   C. The antechamber's floor at the throat's foot: cracked. A relic.
;
; Relics: R1 (the rim gallery), R2 (a ledge in the sump, the harder route:
; a hang in the owl's sight), a heart on each of the Vault's galleries, and
; one in each secret: seven.
; Par 4:00 with the Eclipse. Expert line, about 1:45: run every rhythm
; without stopping, never hop a slot, plunge the Eclipse twice per pass.
;
